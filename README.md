# 量化价值投资分析系统

基于 **AkShare** 的 A 股长线价值投资量化分析工具，按照四步逻辑对目标股票进行全面评估。

## 功能概述

| 步骤 | 内容 | 说明 |
|------|------|------|
| Step 1 | 基本面筛选 | ROE / 股息率 / 资产负债率 / 利润质量，判断是否符合长线价值投资标准 |
| Step 2 | 估值锚定 | 自由现金流折现（DCF），输出保守 / 中性 / 乐观三情景内在价值 |
| Step 3 | 市场情绪 | 全市场 PE 中位数 + 10 年期国债收益率 → 股债性价比及历史分位数 |
| Step 4 | 综合建议 | 结合估值和情绪，给出具体操作建议（大幅买入 / 分批建仓 / 持有观望 / 减仓） |

## 使用方法

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 运行分析（默认分析 000001 平安银行）
python old_stock_analysis.py
```

## 默认参数

- **目标股票**: `000001`（平安银行）
- **数据范围**: 2016-01-01 至今
- **基本面年份**: 2021-2025（共 5 年）
- **DCF 参数**:
  - 保守：增长率 7% / 永续 2% / WACC 9%
  - 中性：增长率 10% / 永续 3% / WACC 8%
  - 乐观：增长率 13% / 永续 5% / WACC 7%

## 输出

- 终端打印：各步骤详细分析结果 + 最终摘要
- `charts/valuation_000001.png`：股价 vs 内在价值走势图（matplotlib）
- `charts/valuation_000001.html`：交互式估值图（Plotly，可选）

## 依赖

Python 3.9+ / akshare / pandas / numpy / matplotlib / plotly / scipy
